## Deskripsi Proyek Ringkasan fungsi dan kegunaan program

Sistem Manajemen Peminjaman Costum merupakan sebuah aplikasi berbasis Java yang dibuat untuk membantu proses pengelolaan peminjaman kostum secara lebih terstruktur dan efisien. Program ini digunakan untuk mengelola data kostum, data peminjam, serta proses transaksi peminjaman dan pengembalian kostum.
Dengan adanya sistem ini, proses pencatatan yang sebelumnya dapat dilakukan secara manual dapat digantikan dengan sistem digital sehingga data lebih mudah disimpan, dicari, dan dikelola. Pengguna dapat melakukan penginputan data kostum, mencatat transaksi peminjaman, serta melihat informasi terkait status kostum yang tersedia maupun yang sedang dipinjam.
Aplikasi ini bertujuan untuk meningkatkan kemudahan dalam pengelolaan administrasi peminjaman kostum, mengurangi kesalahan pencatatan, serta membantu pengguna dalam memantau aktivitas peminjaman agar menjadi lebih efektif dan terorganisir.
